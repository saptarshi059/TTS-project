## ⚠️ Important: Setup instructions

Some models (e.g. BGE-large) may stall due to XET backend issues.

1. Before running any code, load:`source src/utils/hf_env.sh` 
2. Sampled datasets are all provided in `sampled_data`
3. Download the corpus for FRAMES with `src/utils/download_frames_corpus.py`
4. Create an index for each dataset with `src/utils/create_index.py`
