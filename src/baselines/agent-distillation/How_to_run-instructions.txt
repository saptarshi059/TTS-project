1. Run create_ds.py to format the datasets to what they want.
2. Edit run_agent_student.sh with the name of the dataset you want to run.
3. From the root of the repo (agent-distillation-main) run ./scripts/inference/run_agent_student.sh
4. Let the script run.
5. Change the name of the dataset you are running in remove_elements.py
6. Once it inevitably crashes (when you see "connection error") run remove_elements.py
7. Run these three for good measure

pkill -u $(whoami) -9 python
pkill -u $(whoami) -9 VLLM
pkill -f run_agent_student.sh

8. Restart the script till it completes - it doesn't take a long time, but just needs constant monitoring.
